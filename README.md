# متجر باقات WE للإنترنت المنزلي (WE Home Internet Plans Store)

منصة تجارة إلكترونية متطورة مخصصة لبيع وتجديد باقات الإنترنت المنزلي (DSL / VDSL / فايبر) التابعة للشركة المصرية للاتصالات (WE) في جمهورية مصر العربية، معتمدة على واجهة عربية بالكامل (RTL First)، وبوابة دفع يدوية للمحافظ الإلكترونية المصرية وتطبيق InstaPay، مع لوحة تحكم إدارية للتحقق اليدوي والتفعيل الفوري.

---

## 1. المميزات والخصائص المعمارية (Phases 1–6)

- **واجهة عربية أصيلة (RTL First):** تصميم عصري يراعي اتجاه القراءة العربي والخطوط الطباعية (`Readex Pro` للعناوين و `IBM Plex Sans Arabic` للنصوص) مع استخدام الأرقام اللاتينية داخل الخطوط الطباعية الجدلية (`tabular-nums`) لقراءة الجيجابايت والأسعار بأعلى دقة.
- **مشهد ثلاثي الأبعاد تفاعلي (3D Hero Visual):** مبني بتقنية Three.js مع حلقة طاقة تفاعلية وإيقاف ذكي عند عدم الرؤية للحفاظ على استهلاك المعالج والبطارية، وبديل خفيف `Hero3DFallback` للأجهزة الضعيفة ووضع `prefers-reduced-motion`.
- **البصمة التصميمية (GB Gauge):** حلقة طاقة تفاعلية مبنية بتقنية SVG لعرض سعة الباقة كرقم بطولي في قلب البطاقة مع توهج ديناميكي وحركة ملء تحاكي تدفق البيانات.
- **كتالوج رسمي دقيق (33 باقة):** جميع باقات سوبر، ميجا، ألترا، ماكس، وإليت مسجلة بأسعارها وسعاتها الرسمية بدون أي تزييف أو ادعاء بأن الباقات "غير محدودة".
- **بوابة دفع يدوية مخصصة ومؤمنة:** دعم فودافون كاش، إنستاباي (`InstaPay`)، اتصالات كاش، وأورنج كاش مع عداد تنازلي حقيقي مدته 60 دقيقة وتنبيهات عند 10 دقائق ودقيقتين، ورفع إيصال التحويل مع فحص الحجم (أقصى حد 5MB).
- **نظام خصم الترحيب (50% للعملاء الجدد):** آلية منع الاحتيال الثلاثية المشددة (مرة واحدة لكل حساب، ولكل رقم تليفون أرضي، ولكل رقم محمول موثق، مع نافذة صلاحية 7 أيام من التسجيل).
- **لوحة تحكم إدارية كاملة (12 وحدة في `/admin`):**
  1. مؤشرات الأداء الحية ومبيعات اليوم/الأسبوع/الشهر.
  2. طابور التحقق من التحويلات اليدوية مع كشف تكرار أرقام العمليات وعدم تطابق المبالغ.
  3. إدارة الطلبات مع تصدير كشوف الحسابات بصيغة CSV العربية (`UTF-8 BOM`).
  4. إدارة باقات وي وتعديل الأسعار وسرعات الخط مع توثيق التغييرات.
  5. سجل العملاء وقاعدة الخطوط الأرضية المسجلة ونظام حظر الحسابات المشبوهة.
  6. إدارة الحملات التسويقية مع شريط حماية مالي للحد الأقصى للخصم.
  7. إدارة حسابات المحافظ الإلكترونية وملاحظات رسوم التحويل.
  8. إدارة المحتوى ونصوص الواجهة والأسئلة الشائعة وتذاكر الدعم المباشر.
  9. الإعدادات التشغيلية، مدة العداد التنازلي، وأكواد المحافظات المسموحة (`013, 02, 03`).
  10. فريق العمل وإدارة الصلاحيات عبر 4 أدوار (`super_admin, verifier, support, auditor`).
  11. سجل تدقيق أمني غير قابل للتعديل (`Audit Logs`) مع تفاصيل المنفذ وعنوان IP.
  12. تقارير الكفاءة التشغيلية ونسب الإنجاز ومتوسط زمن مراجعة الإيصالات.
- **ترسانة أمنية مؤسسية:** ترويسات أمان HTTP مشددة (`Content-Security-Policy`, `Strict-Transport-Security`, `X-Frame-Options`, `X-Content-Type-Options`, `Permissions-Policy`) وملفات `sitemap.xml` و `robots.txt` لتغطية محركات البحث ومنع فهرسة المسارات الحساسة.

## 2. متطلبات التشغيل والبدء السريع

### المتطلبات
- **Node.js:** الإصدار 20 أو أحدث (مختبر بنجاح على Node v24).
- **npm:** الإصدار 10 أو أحدث.

### خطوات التثبيت والتشغيل المحلي

1. **استنساخ المشروع وتثبيت الحزم:**
```bash
git clone <repository-url>
cd "shop new premuim"
npm install
```

2. **إعداد متغيرات البيئة:**
قم بنسخ ملف المتغيرات النموذجية إلى `.env.local`:
```bash
cp .env.example .env.local
```
ثم قم بملء مفاتيح مشروع Supabase الخاص بك:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
NEXT_PUBLIC_SITE_URL=https://we-store.eg
```

3. **تطبيق هجرة قاعدة البيانات والبيانات الأولية:**
قم بتطبيق ملف الهجرة ثم ملف البذور داخل Supabase SQL Editor:
- `supabase/migrations/20261001000000_init_schema.sql` (15 جدولاً وفهارس وسياسات RLS)
- `supabase/seed.sql` (34 باقة رسمية، وسائل الدفع، الحملة الترحيبية، الإعدادات، والأسئلة الشائعة)

4. **تشغيل خادم التطوير:**
```bash
npm run dev
```
افتح المتصفح على [http://localhost:3000](http://localhost:3000).

5. **فحص البناء والاختبارات الآلية:**
```bash
# تشغيل الاختبارات الآلية الشاملة (70 اختباراً تغطي المراحل من 1 إلى 6)
npm test

# فحص بناء الإنتاج الشامل وتوليد المسارات الثابتة والديناميكية (70 مساراً)
npm run build
```

## 3. مصفوفة التحقق والاختبارات الشاملة (70 Tests Passing)

تم بناء وتنفيذ 70 اختباراً آلياً باستخدام محرك اختبارات Node.js المدمج تغطي كافة جوانب المنصة:

- **المرحلة 1 (Phase 1 Foundation - 18 اختباراً):**
  - مطابقة الكتالوج لـ 34 باقة وفق البند 7 (سوبر 16، ميجا 8، ألترا 6، ماكس 3، إليت 1).
  - بقاء `speed_mbps` فارغاً `null` افتراضياً، وحفظ `tier_note_raw` بدون عرضه للجمهور.
  - التحقق من تنسيق أرقام الهواتف الأرضية والمحمولة في مصر (013 للقليوبية، 02 للقاهرة).
  - العداد التنازلي للخادم (60 دقيقة) ومصفوفة الانتقال القانونية لحالات الطلب.
- **المرحلة 2 (Phase 2 Public UI - 10 اختبارات):**
  - محرك الفلترة والبحث الفوري في صفحة `/plans`.
  - توليد الروابط الفريدة (`slugs`) لجميع الـ 33 باقة للـ Static Generation (SSG).
  - التأكد من الرابط الرسمي لشركة وي (`https://te.eg`) وقنوات الدعم الرسمية.
- **المرحلة 3 (Phase 3 Auth & Discount - 8 اختبارات):**
  - حساب خصم الـ 50% وسقف الخصم الأقصى واستبعاد الباقات السنوية.
  - محرك منع الاحتيال (منع تكرار الخصم لنفس الحساب أو نفس الخط الأرضي أو نفس المحمول).
  - نافذة صلاحية الـ 7 أيام لهدية التسجيل.
- **المرحلة 4 (Phase 4 Checkout & Payment - 7 اختبارات):**
  - تأكيد رقم الخط الأرضي المزدوج وتطابقه.
  - تجميد لقطة الأسعار اللحظية (`Price Snapshot`) في الطلب.
  - قيود أمان رفع الإيصال (حجم الملف <= 5MB، وجود رقم الحوالة والراسل).
- **المرحلة 5 (Phase 5 Admin Dashboard - 17 اختباراً):**
  - دورة عمل طابور التحقق (اعتماد، تشغيل، إتمام، رفض، طلب معلومات).
  - تنبيهات مكافحة الاحتيال اللحظية (تكرار رقم العملية، عدم تطابق المبلغ، عميل مشبوه).
  - توافق ملفات CSV مع Microsoft Excel عبر `UTF-8 BOM`.
  - مصفوفة صلاحيات الأدوار (RBAC) لـ `super_admin, verifier, support, auditor`.
  - هيكل سجل التدقيق الأمني غير القابل للتعديل (`Audit Logs`).
- **المرحلة 6 (Phase 6 E2E Simulation - 10 اختبارات):**
  - محاكاة متكاملة لدورة حياة العميل الحقيقية من التسجيل حتى شحن الخط بنجاح وتوثيق العملية في سجل التدقيق الأمني ومنع إعادة استخدام الخصم بعد استهلاكه.
